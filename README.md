# Peggle Roguelike

This project is a video game inspired by Peggle with Roguelike elements. The main goal of the game is to gain as much money as possible to continue playing. In order to drop a ball into a grid of pegs, the player must spend an ever-increasing amount of money. As the game progresses, the player can add upgrades to their board that provide additional ways to gain money. The game also features sets of themed levels with characters that provide challenges to the player's board.
